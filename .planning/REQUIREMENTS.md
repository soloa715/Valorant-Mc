# Project Requirements

## Core Requirements & Specifications

### 1. Agent Mechanics
- Maintain and balance 17 implemented agents (Jett, Reyna, Phoenix, Raze, Sova, Omen, Brimstone, Viper, Cypher, Killjoy, Breach, Sage, Skye, KAY/O, Yoru, Astra, Gekko).
- Accurate ultimate point counters, cooldown management, and visual/audio indicators.

### 2. Match & Economy System
- Support 5v5 team balancing, lobby creation, and administrative controls.
- Dynamic credits economy (starting credits, kill rewards, win/loss streak bonuses).
- Persistent VP currency for skin unlocks.

### 3. Maps & Environment
- Auto-generation for built-in maps (`ascent`, `split`, `bind`).
- Map setup wizard for custom Minecraft worlds (`/vmapsetup`).

### 4. Technical & Platform Compatibility
- Ensure server compatibility with Paper 1.21.4 / 1.21.11.
- Ensure client companion compatibility with Fabric Loader 0.19.2.
- Provide automated build and local test deployment tools (`run-server.bat`, `lan_sync_server.py`).
